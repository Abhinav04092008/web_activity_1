## 📌 Project Description

The Royal Feast is a modern and responsive restaurant website designed to provide an elegant online dining experience.

The website showcases delicious food items, special offers, customer reviews, restaurant information and table reservation details.

## 🚀 Technologies Used

- HTML5
- CSS3
- Google Fonts

## ✨ Website Features

1. Attractive Hero Section
2. Restaurant About Section
3. Delicious Food Menu
4. Special Offers and Discounts
5. Why Choose Us Section
6. Customer Reviews
7. Food Gallery
8. Table Reservation Form
9. Contact Information
10. Responsive Design
11. Professional Footer
